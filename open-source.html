StraightPic

StraightPic does not include any third-party open source components. Its perspective correction, cropping, and export pipeline is built entirely on first-party Apple frameworks — SwiftUI, Core Image, Core Graphics, Metal, ImageIO, Photos, AVFoundation, and StoreKit — which are provided under Apple’s own SDK and platform licenses rather than an open source license.

Because the correction runs on device using those frameworks, StraightPic ships no bundled open source libraries and makes no open source network calls. There is accordingly nothing to attribute for this app today.

If a future release of StraightPic adds an open source dependency, it will be listed here with its copyright notice, license, and project URL before that release ships.
